New hypotheses

Five testable ideas, ranked by expected DTI per unit of effort

Each names the exact layers, the physical signature, why it catches faults the USGS/INGENIOUS catalogue misses, and how it differs from everything already tried in this group's 24 live-scored artefacts. Ranked by expected DTI gain ÷ implementation cost. H-24 is the one that is built and shipped.

2H-25Relocation, not detection: the catalogue's own traces are misregistered by up to ~400 m, so re-emit the catalogue geometry displaced onto the lidar scarp crest within a 500 m search window.labels.tif trace skeletons ⊕ lid_lapneg_max (crest convexity) ⊕ lid_upface_max; constrained argmax displacement per trace segmentHermant et al. A displaced copy lands on the true surface expression, which is the prediction target, and is by construction a pixel the catalogue does not contain.Prior work used the catalogue only as a prior or a mask; nobody moved it. 5H-28Coverage-void targeting: concentrate the budget where mapped-geology density is lowest but lidar scarp evidence is highest — the intersection of “unsurveyed” and “structurally permissive”.sgmc_density9 (USGS SGMC line density, 2.1 km window) inverted ⊕ lid_*_max composite ⊕ lidar validityThe catalogue is a compilation of existing maps, so its gaps follow map coverage, not geology. A pixel with strong lidar scarp expression and no mapped structure nearby is the single most likely place for an expert to add a new fault.This is the mechanism behind H-24's habitat weights, made explicit and testable on its own: it predicts skill should rise with (scarp evidence × map-void), which is a one-line addition to the attribution regression.+0.005 … +0.03lowqueued
New external data needed, and whether it is obtainable. H-24, H-25 and H-26 need nothing new: every layer is already on disk and hash-pinned in data/external/. H-27 needs the GeoDAWN Area-2 flight-line geometry, which ships inside the official USGS release already mirrored here (area2_flight_path.zip, 305,715,443 B, listed in data/external/observed_files.json from ScienceBase item 657e1d85d34e23d3533209f7). H-28 needs full-footprint 1 m lidar: the free official source is the USGS 3DEP 1 m tile set via tnmaccess.nationalmap.gov, public domain, no key — 706 of the 716 required tiles were already fetched by a sibling repository and their URLs recorded; the remaining 24.6 % of the footprint (north-east quadrant) is unreachable from this sandbox, which cannot resolve that host, but is reachable from GitHub Actions and from any ordinary machine.
Honest status of these numbers. The ΔDTI column is an order-of-magnitude expectation derived from the metric algebra in submission-build.json, not a measurement. No offline proxy validates placement (best Spearman ρ = 0.326 over 24 live artefacts), so none of these ideas can be confirmed without a submission slot. H-25 is ranked second because it is the only one that needs no new data and no new model.
