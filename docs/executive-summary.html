Step by step

Upload procedure

  1. Download gemsdoe23-h24-dispersed-habitat-20261002-ada8df14-nan.tif with the button above. It is the official variant: NaN outside the footprint, exactly as the format rules require.
  2. Sign in at drivendata.org/competitions/306 and open the Submissions tab. The account must be the entity registered for this competition.
  3. Upload the .tif unchanged. Do not open and re-save it in GIS software: that rewrites the nodata tag and can turn NaN into a large negative sentinel.
  4. Paste the note from the copy box above into the submission description field. It records the method, the emitted pixel count, η and the file hash, so the upload is traceable back to this repository.
  5. Record the score the moment it appears: python scripts/record_score.py --score <X> --id e29e8f04. Every live score is an observation that improves the |G| and skill estimates on the evidence page.
If the uploader rejects the file with “Predicted values must be in range [0, 1]”, upload the all-finite variant instead (gemsdoe23-h24-dispersed-habitat-20261002-ada8df14-allfinite.tif). It is byte-identical inside the footprint and writes 0.0 rather than NaN outside it; some server-side checkers read the whole array before applying the footprint mask. Both variants are produced and validated by scripts/build_submission_live.py.
Rules that constrain the decision

Before you spend the slot

Three uploads per rolling seven days

Official rules §3.2/§3.4. Slots are the only ground-truth channel, so the standing rule in this repository is: never upload something that has not beaten the current best on a validated holdout. That rule cannot be satisfied honestly this session, because no offline proxy correlates with the live board (best ρ = 0.326). The decision rule actually used is on the next card.

Decision rule used instead

Upload this file if you accept the projection: DTI = TP/(0.2·TP + 0.197·A + 0.8·(|G| − TP)) with A = 100,000, |G| ∈ [6k, 15k] and q ∈ [0.04, 0.11] gives 0.124–0.337. The group's verified best is 0.1922 at q = 0.0475 and η = 0.40; this emission has η = 0.946 at a smaller budget, which is a measured geometric improvement worth up to 2.4× in q at unchanged alignment, and the habitat ranking is the only component with out-of-family validation. Break-even with 0.1922 needs q ≈ 0.04 at |G| = 10,000 — i.e. no better than h19-5's measured value.

One submission for both prize rounds

The same file is scored on the private test set at the close (Initial Round, 5 × $10,000) and re-scored against the expanded expert labels in the Final Round ($250,000 pool). Known USGS/INGENIOUS fault pixels are masked out in both rounds (staff ruling, forum 11516), so nothing is gained by painting the catalogue.
