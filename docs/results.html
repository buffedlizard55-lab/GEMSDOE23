H19-5 forensic reading

Why might it score better? Plausible mechanism, not proven cause

Its own project page's account

The linked 19GEMSDOE page describes H19-5 as a sparse candidate set supported by several physical lines: power-law fault-length scaling, backward thermal/geochemical conduit reasoning, high-resolution topographic openness/local relief, and geophysical lineaments. It describes an approximately 2.45% per-quadrant emission budget.

These are claims from a team-maintained project page. This checkout has not reproduced its feature extraction, folds, or scores. They are not independently verified measurements.

Metric-compatible rationale

The official metric uses `α=0.2`, `β=0.8`, so its false-negative coefficient is larger than its false-positive coefficient. A limited set of plausible, thin traces could improve recall while limiting false-positive mass; the 300 m triangular kernel also tolerates small location offsets.

That describes an incentive in the metric; it does not show which H19 feature caused the score. Thin binary output alone is not evidence of geological correctness.

Best defensible answer: H19's score is an observed public result, but the causal explanation is unknown. The multi-line corroboration and controlled output density are plausible reasons; only matched ablations, independent spatial folds, and artifact provenance can distinguish them from data leakage, split luck, or unrelated changes.
The question: can we exceed .1894?

Already above that value in the supplied record; beating the leader is a different problem

  • The supplied history already lists H19-5 at 0.1922, which is 0.0028 above H19-4's 0.1894. The official board snapshot also shows 0.1922 and 0.1894 as public scores, though it does not establish the file/account mapping.
  • The prompt-reported former-leader `.3049` is not the current public leader: the 2026-10-02 page showed `.3195`, a gap of 0.1273 from the supplied H19-5 score of `.1922`. The current second-place score was `.3042`. The historical provenance of `.3049` was not authenticated here.
  • It is possible in principle to generate a higher public score; it cannot be promised. Public leaderboard scores can overfit and do not reveal the private Phase 1 or Phase 2 outcome.
  • This repository has not trained or validated a new candidate. Therefore it cannot responsibly claim a new expected score, nor recommend spending a weekly upload slot.
What must happen next

Turn explanation into an experiment

  1. Obtain the authorized `training_features.tif`, `labels.tif`, and official `sample_submission.tif` from the competition data tab; inspect tags, masks, and encodings rather than guessing.
  2. Establish a reproducible baseline and freeze spatial blocks/buffers, the DTI implementation and 300 m support, transforms, and equal candidate-emission budget. No real holdout incumbent exists in this checkout yet.
  3. Audit the public GeoDAWN radiometric files and exact grid overlap, then compare the top-ranked K/eU/eTh hypothesis with the same-fold baseline, including lithology, moisture, flight-line, and sensor ablations.
  4. Report foldwise DTI, calibration, all three uncertainty terms, coverage provenance, and error distances. Only if the preregistered gate passes should a uniquely named TIFF be validated against the sample template and considered for a weekly slot.
